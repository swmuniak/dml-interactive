# Disciple Making Lab — 10-Module Interactive Curriculum

A zero-build-step static web curriculum designed for local church teams of 4–8 (pastors, elders, and lay leaders) to cultivate Christ-centered, reproducing discipleship across 10 focused modules.

- **Live Site:** https://swmuniak.github.io/dml-interactive/
- **Run Locally:** Open `index.html` directly in any browser or run `python -m http.server 8765` from this directory.

## What's Included
- **10-Module Chunked Curriculum (`data/curriculum.js`):** 4 phases, Pre-Launch Module 0 Gate, 5-step module progression, real-church scenario checks, auto-saved local team workbook notes, and a Year-2 Sustainability Hub.
- **16 Interactive Visual Tools (`data/tools.js`, `js/diagrams.js`):** Click-to-inspect SVG diagrams, 3-minute napkin teaching scripts, worked church examples, guardrails, and comparisons against the original workbook diagrams (`diagrams/`).
- **40-Term Glossary (`data/glossary.js`):** Inline hover/tap tooltips plus a slide-over reference drawer.
- **Editorial Illustrations (`assets/images/`):** Six cohesive editorial illustrations anchoring the home overview, C&MA Fourfold Gospel centerpiece (Cross, Laver, Pitcher, Crown), and all four phases.
- **Curriculum Audit Reports (`reports/`):** Multi-agent specialist evaluations (Theologian, Lauded Disciplemaker, Senior Pastor, Learning Specialist) and the Polymath Editor's redesign synthesis.
